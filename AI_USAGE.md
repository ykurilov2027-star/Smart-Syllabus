# AI usage record

## Практична робота №14

- AI-асистент використовувався для створення walking skeleton, контрактів, архітектурної документації, тестів і первинної перевірки реалізації.
- Код застосунку в runtime використовує детермінований локальний `mock`; викликів Gemini/OpenAI чи інших зовнішніх AI API під час тестів немає.
- Результат mock відтворюється з `eval/cases.json`; контрольовані збої дають змогу перевірити обробку помилок без зовнішнього сервісу.
- Людина має перевірити всі вилучені дедлайни, теми та бали; цей прототип не гарантує точність навчального змісту.
- Конфігураційний ключ не потрібен mock-провайдеру, не журналюється, не зберігається в SQLite і не повертається health endpoint.
- Перевірка виконання: `python -m pytest` — 13 тестів пройшли; тести використовують тимчасове сховище.

## Межі використання

У ПР14 Gemini-compatible інтеграція навмисно не реалізована. Не передавайте реальні ключі, персональні дані чи непублічні силабуси до прикладів/журналів; перед увімкненням зовнішнього провайдера слід визначити правила згоди, зберігання та видалення даних.
