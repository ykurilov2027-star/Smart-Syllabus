# ADR 0003: абстракція провайдера і модель

- **Контекст:** ПР14 має зафіксувати межу між AI-кодом і прикладною логікою без платних API-викликів.
- **Контекст:** Надалі планується Gemini API із ключем лише з середовища.
- **Рішення:** Сервіс залежить від gateway та типізованого provider-контракту, а не від SDK постачальника.
- **Рішення:** `mock` є значенням за замовчуванням; Gemini-compatible реалізація поки повертає `not_implemented`.
- **Рішення:** `LLM_PROVIDER` перемикає реалізацію, `LLM_MODEL` задає назву моделі, секрет читається з `LLM_API_KEY` або сумісного `GEMINI_API_KEY`.
- **Наслідки:** Усі тести працюють локально без мережі й витрат; схема результату однакова для провайдерів.
- **Наслідки:** Реальне з'єднання, промпт і політики повторів залишаються поза ПР14.
