# ADR 0002: SQLite для прототипу

- **Контекст:** Каркас має зберігати структуровані результати та працювати локально без окремого сервера БД.
- **Контекст:** Вихідний текст і секрети зберігати не потрібно.
- **Рішення:** Використовувати SQLite із файлом, заданим `DB_PATH`, та створювати таблицю кодом під час ініціалізації.
- **Рішення:** Таблиця містить UUID запису, JSON результат і час створення.
- **Наслідки:** Тести можуть передавати тимчасовий шлях; локальний запуск не потребує зовнішньої інфраструктури.
- **Наслідки:** Для конкурентного навантаження/розгортання потрібна окрема оцінка міграції та транзакцій.
